Cloud compute capacity for Project Atlas was increased by approximately 30% in August, coinciding with an expanding pilot program. During the same month, average API response times improved compared with July, and engineering carried out performance initiatives including query optimization, caching improvements, and frontend performance work. The source does not establish which factor(s), if any, caused the improvement in response times. The team plans to continue monitoring capacity as pilot usage grows.
